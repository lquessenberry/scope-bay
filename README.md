# Scope Bay

Mid-century starship instrument doodads — TOS-style CRT scopes and 1968 slab graphics with Microgamma triglyphs.

Four instruments per deck. Scroll to wake the next set; off-screen boards sleep.

## Run

```bash
npm install
npm run dev
```

## Notes

- **Bridge CRT** — phosphor sweeps, Lissajous, PPI, blink banks
- **1968 slab** — hollow glass plaques, life bars, film bands, align locks
- Tokens: `data-phosphor`, `data-speed`, `data-era`
